### 1、 js单行替换

```javascript
//[\s\S]*?\n
```

> // 使用 //(?!._\.._\.).\*\n 可以避免将网址等也替换掉

### 2、 js多行替换
```javascript
/\*(.|\r\n|\n)*?\*/
```

### 3、html无换行注释
```html
<!--(.*?)-->
```

### 4、 html有换行注释
```html
<!--([\s\S|\r]*?)-->
```
> <!--([\s\S|\r]*?)--> 也可以匹配到html无换行注释，所以只用这一个也可以

### 5、编辑器内所有空行
```javascript
^\s*(?=\r?$)\n
```
