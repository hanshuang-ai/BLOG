### 描述

window.open如果只是直接调用window.open('url'),如果使用多个页面，页面肯定只会显示一个。

### 需求

在网站点击某个栏目链接的时候： 1、需要打开对应的栏目信息，显示相关资讯 2、跳转到网店，供用户购买

### 实现1

```
window.open('url',a)
window.open('url',b)

关键点就是url后面的a和b对页面进行不同的区分
这两个值不能不填，也不能填一样的，否则就只会打开一个页面
```

`注意：open()方法会都打开或者查找窗口，也就是说在浏览器未打开相应窗口的情况下 会打开该窗口，如果浏览器已经打开了相应窗口，则会跳转到该窗口，不会再次重新打开`

## 实现2

```
var url = ["url1", "url2"]
  for (var i = 0; i < url.length; i++) {
    //window.open(url[i], '_blank');
    window.open(url[i], 'i');
  }
  
  window.open里面的'_blank'可以换成i,这样相当于给每个新开的窗口命名
  这样再次点击的时候就会查找窗口，而不是再次新开窗口，如果使用'_blank'
  则每次点击都是新开窗口，可以看作是命名了相同的名字。
```
