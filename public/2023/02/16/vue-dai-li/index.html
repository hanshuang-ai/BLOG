vue-cli-service serve其实是开了一个node服务器，请求/api/bbb的时候，会被中转到https://aaa/bbb，简单理解就是根据vue.config.js的配置将/api替换为''

1. vue.config.js 设置

// vue.config.js
devServer: {
        proxy: {
            "/api": {
                target: "https://aaa/",
                secure: true,
                changeOrigin: true,
                pathRewrite: {
                    "^/api": ""
                }
            }
        }
    },
