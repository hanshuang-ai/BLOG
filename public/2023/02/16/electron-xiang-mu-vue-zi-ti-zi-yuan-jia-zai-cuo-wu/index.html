electron项目vue字体资源加载错误

发表于2023-02-16|更新于2025-10-22|electron
|浏览量:

electron + Vue 项目运行的时候，一切正常。使用 electronBuilder打包后，Vue的字体资源会加载错误，解决方法如下：

//vue.config.js
pluginOptions: {
        //electronBuilder
        electronBuilder: {
            customFileProtocol: "./"
        }
    },
